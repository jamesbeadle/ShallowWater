# Shallow Water Demo

The Unity project for the first game in the Shallow Water series.

**Status:** not yet created. This folder is the destination for a fresh Unity project:

1. Open Unity Hub and install **Unity 6.3 LTS** if it isn't installed.
2. New project → **Universal 3D** template.
3. Set the project location so the project root is this folder (`games/shallow-water-demo`).
4. Commit the generated project — the repository's root `.gitignore` already excludes `Library/`, `Temp/`, and the other generated folders.

Planning for this game lives in [docs/shallow-water-demo/plan.md](../../docs/shallow-water-demo/plan.md); the story it tells is defined in [docs/story.md](../../docs/story.md).
