# Playing the current build

1. Clone the repository and open the folder in Unity Hub with Unity 6 LTS (any 6000.0 release; accept the version prompt).
2. Open any scene, or make a new empty one. Press Play.
3. You are on *Sparrow*, moored at Hopwas bridge on the real canal, pointing south towards Fazeley, with the 1900 one-inch map laid on the ground underneath. W or up is ahead, S or down is astern, A and D or the arrows are the rudder. The boat only answers the helm once it has steerage way.
4. Ahead carries you round the canal's own bends: the helm steers you across the water, and the canal carries you along it. The stop-planks at Huddlesford and the chain across Fazeley Junction hold you with your bow against them. That is the pound.

The game logic lives in `Assets/Game` and knows nothing about Unity. `Assets/Unity` connects it to the scene, and builds the whole pound at runtime so no scene file has to be kept in step with the code yet. The map it builds from is in `Assets/StreamingAssets/map/`, generated by `python3 -m tools.map` (see `docs/map/README.md`). The map is drawn by hand off the 1900 map (`python3 -m tools.map --traced`): the canal, the Tame, the railways, the main roads and the woods so far.
